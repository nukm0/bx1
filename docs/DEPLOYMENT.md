# Развёртывание

## 1. Сервер
Используйте VPS с Ubuntu LTS, Node.js 20+, Docker и доменом. Настройте DNS и HTTPS (например, Caddy/Nginx + Let's Encrypt).

## 2. PostgreSQL
```bash
docker compose up -d db
```
В production задайте сильный `POSTGRES_PASSWORD` и закройте порт БД от публичного доступа.

## 3. Переменные окружения
Скопируйте `.env.example` в `.env`. Заполните:
- `DATABASE_URL`
- `BOT_TOKEN`
- `WEBAPP_URL`
- `OWNER_TELEGRAM_IDS` — числовой Telegram ID владельца
- `SESSION_SECRET`
- `WEB_ORIGIN`

Не используйте `@nukm0` вместо числового ID как механизм авторизации. Чтобы узнать свой ID, запустите бота и отправьте `/id`.

## 4. Установка и миграции
```bash
npm ci
npm run db:generate
npm run db:migrate
npm run build
```
Для первой миграции локально `prisma migrate dev` создаёт миграцию. В production используйте `prisma migrate deploy` после добавления соответствующего script в workspace.

## 5. Reverse proxy
Настройте HTTPS-домен так, чтобы `/api/*` проксировался на API-порт 3001, а остальные пути — на статические файлы `apps/web/dist`. Для SPA включите fallback на `index.html`.

## 6. BotFather
В BotFather настройте Web App URL на HTTPS URL сайта. Перезапустите бота после изменения `WEBAPP_URL`.

## 7. Проверка перед запуском
- открыть Mini App только через Telegram;
- проверить, что неавторизованный запрос к API возвращает 401;
- подтвердить телефон нативным Telegram contact и проверить формат +7;
- проверить, что номер не присутствует в публичном `/api/users/:id`;
- проверить, что модератор не может сам одобрить бан;
- проверить, что только владелец видит статистику и принимает решение по бану;
- проверить резервную копию и восстановление PostgreSQL;
- настроить лимиты запросов, мониторинг ошибок и приватное хранение доказательств.

## Не включено автоматически
- продакшен-хранилище изображений;
- платёжный провайдер и webhook;
- доставка push-уведомлений через Telegram Bot API;
- полноценная панель управления баннерами;
- UI для одобрения магазинов и изменения всех ролей;
- отзывы с подтверждением сделки;
- тесты и CI/CD.
