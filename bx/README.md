# Барахолка — Telegram Mini App

Стартовый MVP маркетплейса объявлений в стиле Avito: каталог, поиск, категории, карточка товара, избранное и создание объявления. Интерфейс адаптируется под мобильный экран и подключает Telegram Web App SDK.

## Что есть
- React + Vite — интерфейс мини-приложения.
- Express API — список объявлений и создание объявлений.
- JSON-файл для простого локального хранения (`server/data.json` создаётся автоматически).
- Telegram Web App SDK: `ready()`, `expand()`, данные пользователя.
- Проверка подписи `initData` на сервере, если задан `BOT_TOKEN`.
- Демо-карточки, если API недоступен.

## Запуск локально
Нужен Node.js 18 или новее.

```bash
npm install
cp .env.example .env
npm run dev
```

Откройте адрес Vite, который появится в терминале (обычно `http://localhost:5173`).

Без `BOT_TOKEN` сервер работает в демо-режиме и не проверяет авторизацию. Не публикуйте такой режим как production-приложение.

## Подключение к Telegram
1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Укажите токен в `.env` как `BOT_TOKEN=...`.
3. Разместите фронтенд и API на HTTPS-хостинге. В этом MVP API ожидается на том же домене под `/api`.
4. В @BotFather настройте Mini App / Web App URL на HTTPS-адрес фронтенда.
5. Откройте мини-приложение через кнопку бота и проверьте создание объявления.

Для локальной разработки из Telegram используйте HTTPS-туннель (например, Cloudflare Tunnel или ngrok) и укажите его URL в настройках бота.

## Что нужно сделать до реального запуска
- Заменить демо-кнопку «Написать продавцу» на ссылку Telegram конкретного продавца.
- Добавить загрузку фото, а не только URL изображения.
- Использовать PostgreSQL вместо JSON-файла при нескольких пользователях.
- Добавить редактирование и удаление своих объявлений, жалобы и модерацию.
- Хранить избранное и владельца объявления на сервере.
- Добавить ограничения запросов, валидацию, журналирование и резервные копии.
- Не доверять `seller`, цене и прочим полям от клиента: определять Telegram user ID из проверенного `initData` на сервере.
